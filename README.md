## 🚀 ENGLISH - Installation & Configuration

### Installation via HACS (Recommended)

1. Open HACS in Home Assistant
2. Go to **Integrations**
3. Click **⋮** (menu) → **Custom repositories**
4. Add: `https://github.com/narfight/oneminai-homeassistant`
5. Select **Category: Integration**
6. Click **Create**
7. Search "1min.ai" and install
8. Restart Home Assistant

### Manual Installation

1. Clone the repo:
```bash
git clone https://github.com/narfight/oneminai-homeassistant.git
```

2. Copy the `oneminai/` folder to `~/.homeassistant/custom_components/`

3. Restart Home Assistant

### Configuration

1. Go to **Settings** → **Devices and Services** → **Create Integration**
2. Search for "1min.ai"
3. Enter your **1min.ai API key** (available at [1min.ai](https://1min.ai))

### Options

Once configured, go to **Settings** → **Devices and Services** → **1min.ai** → **Options**:

| Option | Description | Default |
|--------|-------------|---------|
| **AI Model** | Model to use (gpt-4o, claude-3-5-sonnet, etc.) | `gpt-4o-mini` |
| **System Prompt** | System instruction for the AI | (English by default) |
| **Local Control First** | Execute local home intents before API | `true` |
| **Web Search** | Enable web search to enrich responses | `false` |
| **Number of Sites** | Number of sites for web search | `3` |
| **Max Words** | Max words extracted from web search | `1000` |
| **Request Timeout** | Max time for API response (sec) | `60` |
| **History Limit** | Number of messages kept in context | `10` |

### Usage

#### Via Voice Assistant (Assist)

Once configured, the integration becomes the default agent for Assist:

```
"Turn on the living room"      → Executed locally (fast)
"What's the weather tomorrow?" → Call 1min.ai
"Tell me a joke"               → Call 1min.ai
```

#### Via `oneminai.ask` Service

Call the integration directly from automations:

```yaml
service: oneminai.ask
data:
  prompt: "Summarize the last 3 messages from my chat group"
  model: "gpt-4o"          # Optional, uses configured model
  web_search: true         # Optional
response_variable: ia_response
```

Retrieve the response:

```yaml
- service: notify.telegram
  data:
    message: "{{ ia_response.response }}"
```

### Architecture

#### Processing Flow

```
User (voice/text)
    ↓
Assist (HA)
    ↓
OneMinAI Agent
    ├─ Local First Strategy?
    │  ├─ Yes → Try local intents
    │  │        ├─ Match → Execute & respond
    │  │        └─ No match → Fallthrough
    │  └─ No → Continue
    ├─ Call 1min.ai API
    │  ├─ Reuse existing conversation (context)
    │  └─ Return response
    ↓
User (response)
```

#### Memory Management

- **Cache limit**: max 100 concurrent conversations
- **TTL per conversation**: 1 hour of inactivity
- **Auto cleanup**: on each new message

### Dependencies

**No external dependencies** — uses only libraries built into Home Assistant (aiohttp, voluptuous).

### System Requirements

- **Minimum HA**: 2025.1
- **Integration Type**: Cloud (requires internet for 1min.ai)
- **Timeout**: Configurable (default 60 sec)

### Troubleshooting

#### "Invalid API Key"
- Verify the key is correct at [1min.ai](https://1min.ai)
- Check internet connectivity

#### "Timeout"
- Increase `Request Timeout` in options (max 120 sec)
- Verify 1min.ai is accessible: `curl https://api.1min.ai/api/chat-with-ai`

#### "No intent match"
- Normal — the phrase is unrelated to home automation
- Integration falls back to 1min.ai to respond

#### No conversational history
- Verify `History Limit` > 0
- Ensure you're talking to the same agent (don't switch in Assist)
